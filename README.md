# MySQL Scripts - Valdomiro Ramos

Repositório com scripts SQL para aprendizado e prática em MySQL, contendo exemplos de:

- **Clientes e Endereços**: consultas, joins e views (`vw_lista_customer`).
- **Produtos e Categorias**: consultas, joins, filtros, views (`vw_lista_produtos`) e manipulação de strings.
- **Pedidos e Vendas**: cálculos, filtros, manipulação de datas e views.
- **Cidades e Backup**: backup de tabelas, inserção, atualização e exclusão de registros.
- **Procedures**: exemplos de procedures com cursor e seleção de dados.
